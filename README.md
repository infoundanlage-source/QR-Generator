# QR-Generator

QR-Code Etiketten Generator für **Dymo 57×32 mm** Drucker und PNG-Export.

## Features
- QR-Code Vorschau in Echtzeit
- Dymo-Label Export als PDF (57×32mm)
- PNG-Export (5–40mm, 300 DPI)
- Optionaler Text unter dem QR-Code im PNG
- Mobile-optimiert: Buttons frei positionierbar (Drag & Drop)
- Desktop & Mobile kompatibel

## Dateien
- `qr-generator.html` — Die fertige App (Single HTML File)
- `QR-Generator_Detaillierter_Prompt.md` — Vollständige Spezifikation für KI-Rekonstruktion

## Verwendung
Einfach `qr-generator.html` im Browser öffnen — keine Installation nötig.
